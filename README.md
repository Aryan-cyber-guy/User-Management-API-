🚀 User Management API

A simple RESTful API built using FastAPI, SQLAlchemy, and PostgreSQL to perform basic user management operations (CRUD).

📌 Project Overview

This project allows you to:
  ✅ Create a new user
  🔍 Get a specific user by ID
  ✏️ Update user details
  ❌ Delete a user
  💾 Store all user data in PostgreSQL

It demonstrates how a backend application:
  Handles HTTP requests
  Validates input using Pydantic
  Interacts with a database using SQLAlchemy
  Manages database sessions properly

🛠 Tech Stack:
  FastAPI – Web framework
  SQLAlchemy – ORM (Object Relational Mapper)
  PostgreSQL – Database
  Pydantic – Data validation
